Mermaid and code

Updated 7 Nov 2026Links 3 in · 4 out#example#mermaid#rendering

Build this page and compare it with what you see in Obsidian. If they match, the two things that are hardest to publish both survived.

A diagram

Mermaid output exists only as the SVG a running Mermaid drew. No Markdown converter can produce it.

A second one, to check that two diagrams on one page both arrive:

Diagrams publish light-themed

Resolved colours from Mermaid's default light theme are baked into the SVG, so on a dark site these will look wrong. → Known limits

If they come out empty

Obsidian 1.14 gates diagram rendering per vault, and the plugin reports that rather than working around it. Allow diagrams for this vault and build again.

Highlighted code

Syntax highlighting is also the app's work rather than something in the Markdown, so it is worth checking too.

A table, a callout and a quote

Because they are the other things that look different once styled.

Thing Rendered by Survives?
Wikilink the build yes, rewritten to a relative URL
Dataview table Dataview yes, as a static table
Mermaid diagram Mermaid yes, as SVG
Bases sorting Bases no
Callouts publish as callouts

Including this one. A collapsed callout publishes in whichever state it was rendered, and stays that way.

A plain blockquote, for comparison.

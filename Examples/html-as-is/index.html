This page was published byte for byte

No stylesheet of the plugin's was added to this document, and no script. What is on the server is what is in the vault. The page you are reading has none of the furniture a published note gets — no command bar, no vault tree, no outline rail — because nothing rendered it.

Three files travelled to get here

  • index.html — this page, because it was in scope and the as-is toggle was on.
  • styles.css — because this page names it in a <link>.
  • art/panel.svg — because this page names it in an <img>, at a relative path that still resolves.

And a fourth, which is the interesting one: art/texture.svg is named by nothing in this document. It is a background-image in styles.css, and it is behind the box below. The build resolved it against the stylesheet rather than against this page, which is what a browser does.

If this box has a texture behind it, that resolution worked.

What would have been reported

A reference that resolves to nothing is named in the build report, together with the file that made it — rather than being dropped in silence. That includes the ones only a stylesheet knows about.
